Add {{site_name}} to your OS

Pick your system, copy the link and add it as a community store. It takes about a minute.

{{{os_tabs}}}

ZimaOS

Reads the store listing directly.

{{{zimaos_url_wbr}}}
  1. Open App Store in the ZimaOS dashboard.
  2. Click the ⚙️ Community store icon, then ➕ icon.
  3. Paste the store URL above.
  4. Click Add and refresh the page.
{{icon:info}}Not showing up? Refresh or restart the App Store service.
user@zimaos: ~ 
user@zimaos:~$ curl -s -X POST \
  -H "Authorization: $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"url":"{{zimaos_url}}"}' \
  "http://localhost/v3/app_store/repo"
user@zimaos:~$

CasaOS

Uses a zip archive of the store.

{{{casaos_url_wbr}}}
  1. Open App Store in the CasaOS dashboard.
  2. Click + Add Source.
  3. Paste the store URL above.
  4. Click Add.
{{icon:info}}The link stays the same when new apps are added.
user@casaos: ~ 
user@casaos:~$ sudo casaos-cli app-management register app-store {{casaos_url}} && sudo casaos-cli app-management list app-stores
user@casaos:~$

Homeio

Uses the same zip as CasaOS.

{{{homeio_url_wbr}}}
  1. Open App Store in the Homeio dashboard.
  2. Click + Install, then Manage Sources.
  3. Paste the URL and name it, for example “{{site_name}}”.
  4. Click Add Source.
{{icon:info}}The link stays the same when new apps are added.
Good to know
  • Homeio and CasaOS share one link, so a single zip serves both.
  • Apps appear in the App Store a few seconds after the source is added.
  • If the source is rejected, try latest.zip in place of store.zip.
