# xtools

xtools is a handy toolbox of developer and everyday tools in your browser: converters, generators, encoders, an image cropper, an ID photo maker, an XML diff and more, in categorized tabs and 12 languages. It is a fork of IT-Tools. Everything runs in your browser; nothing is stored on the server.

## Features

- Developer tools: JSON, YAML, Base64, JWT, hashes, UUIDs, regex, cron and more
- Image cropper and ID photo maker
- XML diff and text tools
- Categorized tabs, search and favorites
- 12 languages, light and dark themes

## How to use

1. Open xtools from your dashboard.
2. Pick a tab or search for a tool.

## Before you install

Nothing to set: no settings, no data folder. Your tools run in the browser, so nothing you paste is sent to the server.
