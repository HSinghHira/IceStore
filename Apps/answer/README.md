# Apache Answer

Apache Answer is a question-and-answer site for your team, product or community. People ask questions, post answers, vote, and earn reputation, so knowledge is easy to find later.

## Features

- Questions, answers, comments, votes and accepted answers
- Tags, search and reputation with badges
- Markdown editor with images
- Roles, moderation and review queues
- Plugins for sign-in (OAuth, LDAP), search and storage

## How to use

1. Open Apache Answer right away and follow the install steps. Pick SQLite.
2. Set the site address, name and your admin account.
3. Ask the first question.

## Before you install

Right after installing, open http://[ZIMAOS-IP-ADDRESS]:6835 and finish the install steps (choose SQLite, set the site URL to that address and make your admin account); until then anyone on your network can. Email for sign-ups and notifications is set in the admin panel with your own SMTP server.
