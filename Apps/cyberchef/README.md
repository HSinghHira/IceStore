# CyberChef

CyberChef, made by GCHQ, is a web app for working with data: encode and decode it, encrypt it, compress it, pull things out of it and analyse it. You drag operations into a recipe, and the output updates as you type. It all runs in your browser, so the data you paste stays on your computer.

## Features

- Over 400 operations: Base64, hex, XOR, AES, hashes, compression, regex, dates, networking and more
- Chain operations into recipes and save them
- Magic mode guesses how data is encoded
- Works on text and files up to about 2 GB
- Share a recipe and its input as a link
- No account, no data stored on the server

## How to use

1. Open `http://[ZIMAOS-IP-ADDRESS]:6729` in your browser.
2. Paste your data into the Input box.
3. Drag operations from the left into the Recipe, or use Magic.

## Before you install

Nothing needs to be set first, and it starts in a few seconds. CyberChef has no settings and no login, so keep port 6729 on your home network. Saved recipes and favourites are kept in your browser, not on the server.
