# VERT

VERT is an open-source file converter that runs conversions on your own device with WebAssembly instead of uploading files to a cloud service. It is a private alternative to online conversion sites.

## Features

- Images, audio and documents convert in your browser (ImageMagick, FFmpeg and Pandoc under the hood), so files never leave your device
- 250+ file formats across images, audio, documents and video
- No file size limits and no ads
- Video converts through VERT's shared vertd servers by default
- Nothing stored, nothing to back up

## How to use

1. Open VERT from your dashboard.
2. Drop a file onto the upload box, or click it to pick one.
3. Choose the format you want.
4. Click convert, then download the result.

## Before you install

Nothing needs to be set first. VERT has no settings and stores nothing. Video files are sent to VERT's shared vertd servers for conversion; everything else stays in your browser.
