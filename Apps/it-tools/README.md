# IT-Tools

IT-Tools is a collection of small tools developers reach for every day: token and UUID generators, hashing, JSON and YAML formatters, date and number converters, regex testers, QR codes and many more. Everything runs in your browser, so nothing you paste leaves your computer.

## Features

- Over 80 tools in one place, with search (Ctrl+K)
- Crypto: tokens, hashes, bcrypt, UUIDs, ULIDs, RSA keys
- Converters: JSON, YAML, TOML, XML, Base64, dates, colours, numbers
- Web: URL parser, JWT decoder, HTTP status codes, user-agent parser
- Favourite the tools you use most
- No account, no data stored on the server

## How to use

1. Open `http://[ZIMAOS-IP-ADDRESS]:6728` in your browser.
2. Search for a tool, or pick one from the list on the left.
3. Click the heart on a tool to keep it at the top of the home page.

## Before you install

Nothing needs to be set first, and it starts in a few seconds. IT-Tools has no settings and no login, so keep port 6728 on your home network. Your favourites are kept in your browser, not on the server.
