# Stash

Stash organises a collection of adult videos and pictures. It scans your folders, makes previews, and fills in titles, performers, studios and tags from online databases, so you can browse and search the collection like a streaming site. For adults only.

## Features

- Scans your folders for videos, pictures and galleries
- Previews, sprites and thumbnails, made on your server
- Fills in details from StashDB and scrapers
- Tags, performers, studios, markers and ratings
- Plays in the browser, with a DLNA server
- Plugins and a GraphQL API

## How to use

1. Open `http://[ZIMAOS-IP-ADDRESS]:6746` and follow the setup.
2. Add `/data` as a library folder, then run a Scan.
3. Under Settings, Security, set a user name and password.

## Before you install

Point the `/data` folder at the place you keep the collection; it starts as `/DATA/Media`. There is no login at first: set one under Settings, Security right after the setup, and keep port 6746 on your home network. Most settings live in Stash itself, under Settings. Making previews uses a lot of CPU and disk space the first time.
