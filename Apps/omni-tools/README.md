# OmniTools

OmniTools is a set of handy tools for everyday jobs: resize or convert images, merge and split PDFs, trim videos, change text, work with lists, JSON, CSV, dates and numbers. Files are handled in your browser, so they never leave your computer.

## Features

- Image tools: resize, crop, compress, convert, remove background
- PDF tools: merge, split, rotate, compress, protect
- Video and audio tools: trim, convert, change speed
- Text, list, JSON, CSV, date and math tools
- No ads, no tracking, no sign-in

## How to use

1. Open OmniTools.
2. Search for a tool or pick a group, like Image or PDF.
3. Drop in your file or text and download the result.

## Before you install

OmniTools has no sign-in and keeps nothing on the server: every tool runs in your browser at http://[ZIMAOS-IP-ADDRESS]:6895, so big videos and PDFs use your computer's memory, not your ZimaOS. It needs no folders and no settings.
